Task 9: Simple Banking Account Class

📌 Project Overview

This project demonstrates a simple banking account system developed using Java. It represents a bank account with an account number, account holder's name, and balance. It supports depositing money, withdrawing money, and checking the current balance.

🎯 Objective

- Understand classes and objects in Java.
- Learn how to use constructors.
- Implement methods to deposit and withdraw money.
- Understand encapsulation by keeping fields private.
- Validate transactions to prevent invalid deposits and withdrawals.

🛠️ Technologies Used

- Programming Language: Java
- Concepts: Classes, Objects, Constructors, Methods, Encapsulation, Conditional Statements

✨ Features

1. Account Creation: Creates a bank account with account details and an initial balance.
2. Deposit: Adds money to the account when the amount is valid.
3. Withdrawal: Withdraws money if the amount is valid and sufficient balance is available.
4. Balance Inquiry: Returns the current account balance.
5. Account Details: Displays the account number, holder name, and balance.
6. Transaction Validation: Rejects invalid deposit and withdrawal amounts.

💻 How It Works

1. The "BankAccount" class stores account information using private variables.
2. The constructor initializes the account details.
3. The "deposit()" method adds money to the balance.
4. The "withdraw()" method checks the amount and available balance before withdrawing money.
5. The "getBalance()" method returns the current balance.
6. The "displayDetails()" method displays the account information.
7. The "main()" method creates an account object and demonstrates the operations.
